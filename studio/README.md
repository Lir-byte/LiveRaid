# LiveRaid Studio - редактор карт

Отдельная программа: открывает навмеш карты, на нём рисуют **свои куски навмеша, запретные области, связки, лазания, маршруты ботов и места интереса** и выгружают всё в игру. Мод LiveRaid читает файл правок и применяет его в рейде.

Запуск: `C:\Games\SPT\LiveRaid Studio\LiveRaid Studio.exe` (окно Edge/Chrome в режиме приложения; закрыли окно - программа завершилась). Без exe: `python studio/server.py` (порт 8777).

## Как этим пользоваться

1. **Один раз на карту** зайдите в рейд (можно сразу выйти). Мод сам записывает навмеш, двери, выходы и точки спавна в `BepInEx/plugins/LiveRaid/studio/dump/<карта>.mesh.bin` + `.meta.json` (F12 → «Маршруты через завалы» → «Выгружать навмеш для Studio», по умолчанию вкл.). Это карта в том виде, как её сделала игра, до любых правок.
2. Откройте Studio, выберите карту. Для проверки интерфейса есть «Учебная карта (демо)».
3. Рисуйте. Слева инструменты, справа списки/свойства/проверка/слои, на карте плавающая панель «Этаж».
4. **Ctrl+S / «Выгрузить в игру»** - файл `BepInEx/plugins/LiveRaid/studio/edits/<карта>.json` (прежняя версия уходит в `edits/backup`).
5. Если рейд идёт, мод заметит файл за ~2 секунды (или нажмите Num1) и обновит навмеш, запреты, связки и лазания. Включить показ нарисованного в мире - Num3 (свободная камера покажет результат): куски навмеша зелёные, запреты красные, связки жёлтые, лазания оранжевые, маршруты ботов голубые, места розовые. Маршруты и места ботам достаются со следующего рейда (квесты строятся в начале рейда).

## Инструменты

| Клавиша | Инструмент | Что делает в игре |
|---|---|---|
| V | Выбор | тащить точки и фигуры, двойной щелчок по линии - новая точка, Delete - удалить |
| P | Навмеш | контур → кусок настоящего навмеша (строится в игре Unity-ом на лету и добавляется к навмешу карты); у стыков со старым навмешем мод добавляет связки сам |
| G | Трап | два клика → полоса навмеша заданной ширины с наклоном (доска, трап, пандус) |
| B | Запрет | коробка по трём щелчкам (сторона, глубина); навмеш под ней вырезается - боты не ходят |
| L | Связка | шаг через щель/дыру: связка двух мест навмеша (оба конца на навмеше) |
| R | Лазание | опоры по порядку, J - прыжок, C - присед; бот лезет по точкам (как записанные маршруты; видимое игроку проигрывается, невидимое - сразу в конец) |
| T | Маршрут | квест QuestingBots «LR Path …»: бот идёт по точкам, в каждой пауза/осмотр; туда-обратно/по кругу/один раз, кто ходит, желанность |
| S | Место | точка интереса: входит в маршруты исследования района (лут / осмотреться / засада) |
| M | Линейка | расстояние |

Остальное: **Tab** - план ↔ 3D, **F** - показать этаж под курсором, **A** - все этажи, **PgUp/PgDn** - этаж выше/ниже, **Alt** при щелчке - без прилипания (иначе точки липнут к вершинам навмеша и к вашим же точкам), **Ctrl+Z / Y** - отмена, **?** - все клавиши. Черновик сохраняется сам и предлагается при следующем открытии карты.

Слои карты: лут-точки, двери, выходы, спавны, места, где стояли вы, **ваши следы** и **следы вне навмеша** (красные точки - где вы шли, а навмеша там нет: готовые места для патчей).

## Проверка («Проверка» справа)

Studio сама ищет то, что в игре не заработает: патч не касается навмеша (боты не смогут на него попасть), слишком узкий/маленький/крутой, самопересекающийся контур; запрет закрывает выход; концы связки и лазания не на навмеше; шаг лазания длиннее 3 м без прыжка; точки маршрута мимо навмеша.

## Формат файла (`edits/<карта>.json`, `liveraid-edits/1`)

`Patches` (`Verts`, `Tris`, `Gates` - стыки со старым навмешем), `Blockers` (`C`, `Size`, `Yaw`), `Links` (`A`, `B`, `Cost`, `TwoWay`), `Routes` (как `routes/<карта>.json`: `Points` с `X Y Z Pose Jump`), `Paths` (`Points` с `P Wait Hold`, `Mode`, `Who`, `Desirability`, `MaxBots`, `MaxTime`), `Spots` (`P`, `Kind`, `W`). У каждого объекта `Id`, `Name`, `Enabled`. Лазания, записанные в игре (`routes/<карта>.json`), Studio показывает пунктиром и умеет импортировать (тот же `Id` - дубликата нет).

## Исходники

`server.py` - локальный сервер (читает/пишет папку игры), `web/` - редактор (Three.js, `app.js` - инструменты и проверки, `view.js` - вид, `geom.js` - геометрия), `make_demo.py` - учебная карта, `build_exe.bat` - сборка exe (PyInstaller из `Tools/pytools`, кладёт в `C:\Games\SPT\LiveRaid Studio`). Сторона мода - `src/LiveRaid.Client/Studio/` (`MapDump`, `MapEdits`, `EditsOverlay`).
