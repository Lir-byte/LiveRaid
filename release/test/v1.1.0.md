# LiveRaid 1.1.0 (test) - LiveRaid Studio

New: **LiveRaid Studio**, a map editor (LiveRaid Studio\LiveRaid Studio.exe). It opens the map's navmesh and lets you draw your own navmesh patches, ramps, no-go boxes, links, climbs, bot walks and extra places of interest, then writes them into the game.

- The mod dumps each map's navmesh itself in the first raid on it (studio/dump). Studio opens it, you draw, Ctrl+S - the mod picks the file up in a running raid within ~2 s (Num1 reloads, Num3 shows the edits in the world with the free camera).
- Settings: F12 -> "Routes through blocked places" (Map edits from Studio, reload on the fly, dump the navmesh, show the edits in the world).
- Test status: the in-game part (building navmesh patches at run time, carving, the overlay) has not been tried in a raid yet.

Новое: **LiveRaid Studio** - редактор карт: свои куски навмеша, трапы, запреты, связки, лазания, маршруты ботов и места; правки подхватываются в идущем рейде.
