# LiveRaid 1.0.4

Bots that play like people online, for **SPT 4.1.6**. Needs QuestingBots 1.2.0, SAIN 4.5.1, LootingBots 1.8.0, BigBrain 1.5.0 and Waypoints 1.9.0 (LiveRaid Online: also Project Fika 2.4.x). Install guide: `INSTALL.md`.

## Downloads

- `LiveRaid-1.0.4.zip` - single player (SPT without Fika); it also holds the Online edition, which LiveRaid Launcher switches on
- `LiveRaid-Online-1.0.4.zip` - the same, with the Online edition (Project Fika co-op) already active

## What changed since 1.0.3

- **LiveRaid Online with a server on another machine (dedicated or headless):** the F12 settings used to be locked for everybody, because the host was only recognised by a file next to the server. Now the server keeps its host key (`user/mods/LiveRaid/host.token`) for good instead of making a new one at every start, and a player on another machine puts the text of that file once into the **Host key** field of `BepInEx/config/com.lir.liveraid.cfg` (section `0. Online`) and restarts the game: he is the host, and his settings go to the whole group. A game in the same folder as the server is still the host by itself. The locked F12 now says how to become the host, and the log tells why a game is not one (headless client, no key, wrong key).

# LiveRaid 1.0.4

- **LiveRaid Online при сервере на другом компьютере (выделенный сервер, headless):** настройки F12 были закрыты у всех, потому что хоста узнавали только по файлу рядом с сервером. Теперь сервер хранит свой ключ хоста (`user/mods/LiveRaid/host.token`) постоянно, а не создаёт новый при каждом запуске, а игрок на другом компьютере один раз вставляет текст этого файла в поле **Host key** файла `BepInEx/config/com.lir.liveraid.cfg` (раздел `0. Online`) и перезапускает игру: он становится хостом, и его настройки действуют у всей группы. Игра в той же папке, что и сервер, по-прежнему хост сама. Закрытое меню F12 теперь подсказывает, как стать хостом, а журнал объясняет, почему игра им не стала (headless-клиент, нет ключа, не тот ключ).
