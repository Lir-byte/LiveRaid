# LiveRaid Online - LiveRaid для Project Fika (кооператив)

**LiveRaid Online** - отдельная редакция LiveRaid для игры с друзьями через [Project Fika](https://github.com/project-fika). Всё, что LiveRaid делает с ботами, работает и в кооперативе. Единственное, чего нет, - модуль **After death** (свободная камера после смерти, вселение в бота, рейд-наблюдатель): в Fika рейд продолжается для остальных игроков, у Fika есть своя камера после смерти, а бот, которым управляют на одной машине, рассинхронизировался бы на остальных.

Проверено по коду Fika.Core **2.4.6** (клиент) и Fika.Server **2.4.2** под SPT 4.1.6. QuestingBots 1.1.0 и 1.2.0 требуют клиент Fika не ниже 2.4.3.

## Как это устроено

В Fika боты живут **только на машине хоста** - у игрока, который создал рейд, или на headless-клиенте. Там работают их «мозги»: SAIN, QuestingBots, LootingBots и LiveRaid. Остальные игроки видят ботов как «наблюдаемых» игроков: Fika пересылает им, где бот стоит, что держит в руках, как стреляет, что открывает. Поэтому:

- **Ботами управляют настройки F12 хоста.** На машинах друзей LiveRaid Online в рейде ничего не делает (в логе: `this machine is a Fika client, the host runs the bots and LiveRaid`) - их F12 на рейд не влияет.
- **Серверный мод LiveRaid** ставится один раз - туда, где запущен сервер SPT (у Fika он общий для всех). Снаряжение и уровни ЧВК, их пустой старт, враждебность - оттуда.
- Ставить LiveRaid Online на машины друзей всё равно нужно: если хостом станет кто-то из них (или Fika потребует одинаковый набор модов, см. ниже), мод должен быть на месте.

Что LiveRaid Online делает иначе, чем одиночный LiveRaid:

| Что | Одиночный | Online |
|---|---|---|
| Кто такие «люди» рядом (спавн подальше от людей, «не прыгать на глазах», замеры встреч) | вы | все живые игроки группы; «пустышка» headless-хоста человеком не считается |
| Переход по маршруту / незаметный толчок застрявшего | если вы не видите | если не видит никто из группы (и ваша камера Fika после смерти) |
| Ключи, которые LiveRaid кладёт ботам | только в инвентарь | в инвентарь на хосте + пакет Fika остальным - ключ есть в трупе у всех |
| Ключи, которые кладёт QuestingBots | - | LiveRaid Online отвечает QuestingBots за плагин QuestingBotsFikaSync (список игроков, ключи для всех); если этот плагин стоит - работает он |
| Число ЧВК-ботов (онлайн-лобби) | лобби карты минус вы | лобби карты минус **все** игроки группы (F12 → 6 `Players of the group take lobby places`); заодно легче хосту |
| Обучение по маршруту (F12 → 3) | ваш маршрут | маршруты всех игроков группы - их видит хост |
| Запись маршрутов-обходов (F12 → 10) | у вас | только у хоста (боты живут там) |
| After death, наблюдатель, вселение | есть | нет (настройки убраны из F12 и выключены) |

Двери, рубильники, лут, броски предметов, лечение, смена оружия, голос и уход ботов через выход идут штатными действиями игрока EFT - Fika сам рассылает их остальным (так же, как у SAIN/QuestingBots/LootingBots).

## Настройки - только у хоста (с 0.9.0)

Хост - игрок, на чьём компьютере запущен сервер SPT (сервер один раз создаёт ключ хоста в `SPT_Runtime/user/mods/LiveRaid/host.token` и хранит его постоянно; игра, стоящая в той же папке SPT, читает его сама). **Если сервер на другом компьютере (выделенный сервер, headless):** скопируйте текст файла `host.token` с сервера в поле **Host key** файла `BepInEx/config/com.lir.liveraid.cfg` (раздел `0. Online`) на машине игрока, который должен менять настройки, и перезапустите игру - этот игрок станет хостом. Клиент headless хостом не бывает никогда, а на машине headless настройки группы приходят с сервера. Его F12 LiveRaid - общие настройки группы: игра хоста отправляет их серверу при каждом изменении (сервер хранит их в `shared-settings.json` рядом со своей DLL), остальные получают их при запуске, раз в 3 с при открытом F12 и в начале каждого рейда (если рейд создаёт не хост - боты всё равно живут по настройкам хоста). У остальных меню серое, поверх - «Настройки контролируются только хостом»; «Режим разработчика» (только просмотр) у каждого свой. В журнале: `LiveRaid Online: this machine runs the SPT server - it is the host…` / `…its host's settings are used here, F12 is locked` и `the host's settings taken (version N, M changed)`; на сервере - `the host's settings saved for the group (rev N…)`.

## Установка

**Одиночный LiveRaid и LiveRaid Online вместе не ставятся** - это один и тот же плагин в двух редакциях. Если стоит Fika, одиночная редакция сама выключается и пишет в лог `Project Fika is installed: this is LiveRaid for single player and it stays OFF`.

Каждый игрок группы (хост и друзья):

1. Закройте игру. Тот, у кого сервер, - остановите сервер SPT.
2. Установлены одинаковые версии: Fika (клиент), SAIN 4.5.1, QuestingBots 1.2.0, LootingBots 1.8.0, BigBrain 1.5.0, Waypoints 1.9.0.
3. Распакуйте `LiveRaid-Online-<версия>.zip` в корень игры с заменой. У друзей, которые подключаются к чужому серверу, папка `SPT_Runtime/user/mods/LiveRaid` из архива не нужна (серверный мод ставится только на сервер).
4. В `BepInEx/LogOutput.log` - `LiveRaid Online <версия> loaded` и строка `LiveRaid Online: serves QuestingBots in Fika …` (или `QuestingBotsFikaSync is installed …`).

В начале рейда у хоста: `raid on <карта>: LiveRaid Online <версия> active (Fika host)` (или `Fika headless host`), при группе из нескольких ЧВК - `LR Population: N PMC players in the group - M PMC bots fewer`.

### Рекомендуемые настройки сервера Fika

Чтобы у всех был один и тот же набор модов (иначе у друга без LiveRaid/SAIN всё будет работать, но станет неочевидно, почему боты ведут себя по-разному у разных хостов), в `SPT_Runtime/user/mods/fika-server/assets/configs/fika.jsonc` можно перечислить обязательные плагины:

```jsonc
"mods": {
  "required": [
    "com.fika.core",
    "com.lir.liveraid",
    "me.sol.sain",
    "com.danw.questingbots",
    "me.skwizzy.lootingbots",
    "xyz.drakia.bigbrain",
    "xyz.drakia.waypoints"
  ],
  "optional": []
}
```

Fika сверит набор и хэши DLL у каждого подключившегося и не пустит с другой версией. Это не обязательно - LiveRaid работает и без этого.

Остальное в `fika.jsonc` - на ваш вкус; LiveRaid от этих пунктов не зависит. `allowSpectateBots` и `allowFreeCam` - это камера Fika, с LiveRaid не конфликтует.

### Headless

Headless-хост поддерживается: LiveRaid работает на нём так же, как у хоста-игрока, а его «пустышку» не считает человеком (боты не держатся от неё подальше, не меряют встречи по ней). Для спавн-системы QuestingBots в headless нужен Fika.Headless не ниже 1.5.0 (требование QuestingBots). Логи LiveRaid (`BepInEx/plugins/LiveRaid/logs`, `LogOutput.log`) в этом случае пишутся на машине headless.

## Совместимость модов сборки с Fika

Проверено по коду (декомпиляция установленных DLL и исходники нужных версий).

| Мод | С Fika | Что важно |
|---|---|---|
| **LiveRaid** (одиночный) | ✗ несовместим | использовать **LiveRaid Online**; одиночная редакция при Fika выключается сама |
| **LiveRaid Online** | ✓ | этот документ |
| **SAIN 4.5.1** | ✓ | сам знает про Fika: работает на хосте, на клиентах свой мир не поднимает |
| **QuestingBots 1.2.0** | ✓ | нужен клиент Fika ≥ 2.4.3; список игроков и ключи для остальных - через QuestingBotsFikaSync или LiveRaid Online (он подключается сам, если того плагина нет) |
| **LootingBots 1.8.0** | ✓ | сам знает про Fika (взаимодействия через штатные действия игрока, добавленные патроны рассылает пакетом) |
| **BigBrain 1.5.0** | ✓ | слои мозга - на хосте |
| **Waypoints 1.9.0** | ✓ | навмеш ботов - на хосте |
| **DontShootTheBus 1.1.0** | ✓ | меняет только враждебность ботов к БТР (на хосте, где живут боты и БТР) |
| **Ragdoll Kinetics 1.2.0** | ✓ (внешний вид) | физика тел на каждой машине своя, итоговое положение трупа Fika присылает с хоста - тело может «доехать» на место после падения. Отладочный пункт `Ragdoll Preview (Debug)` держать выключенным: он сам спавнит бота в обход Fika |
| **ConfigurationManager** | ✓ | - |

Удалены из сборки и не рассматривались: SoulPlayer, WatchAnims, RealTargets.

## Что проверить в первом совместном рейде

1. У хоста в `LogOutput.log`: `LiveRaid Online 0.9.9 loaded` без `disabled: …`, затем `raid on … (Fika host)`; у друга - `this machine is a Fika client …`.
2. `LR Population: N PMC players in the group - M PMC bots fewer` (если вас несколько).
3. Боты ведут себя как в одиночной игре: квестуют, лутают, открывают двери (у друга дверь тоже открыта), дерутся, уходят через выходы (у друга бот исчезает).
4. Друг обыскивает труп бота, у которого был ключ (`LR Key: … carries …` в логе хоста), - ключ на месте.
5. В логе друга нет ошибок `Could not find player with id … when trying to spawn item` и `Failed to move spawned item`.
6. Трасса хоста (`BepInEx/plugins/LiveRaid/logs`, F12 → 1 `Log detail` = Detailed) - разбирается как обычно (`tools/raidlog.py`).
